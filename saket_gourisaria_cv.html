02 / Selected work

IoT Intrusion Detection System

Machine Learning / Deep Learning · BotNeTIoT-L01
ONGOING RESEARCH
  • Investigating machine learning and deep learning approaches for distinguishing normal and attack traffic in IoT networks.
  • Built a data-processing pipeline for approximately 2.43M records and 23 numerical features, covering duplicate removal, missing/infinite-value handling, numeric conversion and validation.
  • Conducted EDA across class distribution, descriptive statistics, feature-label relationships, correlations and IQR-based outlier analysis.
  • Compared class-weighted Random Forest, majority undersampling and SMOTE using F1, recall, ROC-AUC, PR-AUC, balanced accuracy, MCC and false-negative rate.
  • Preliminary Random Forest experiments reached approximately 99.99% F1 and ~1.00 ROC-AUC; further experiments are in progress.
  • Developed a TensorFlow/Keras neural-network approach using batch normalization, dropout, class weighting, early stopping and learning-rate scheduling.

Student Academic Risk Prediction System

Machine Learning · Scikit-learn · Streamlit
ML APPLICATION
  • Developed a prototype to identify students at Low, Moderate or High academic risk early enough to support intervention.
  • Compared Logistic Regression, Decision Tree and Random Forest using an 80/20 stratified train-test split.
  • Implemented StandardScaler preprocessing and evaluated models using accuracy, precision, recall and F1-score.
  • Used GridSearchCV for Logistic Regression tuning and analyzed model coefficients for interpretability.
  • Built a Streamlit application featuring individual assessment, class-risk ranking, what-if analysis, mentor allocation, intervention plans and downloadable reports.
  • Best preliminary model achieved approximately 77% accuracy and 77% F1 on the project's synthetic dataset.
